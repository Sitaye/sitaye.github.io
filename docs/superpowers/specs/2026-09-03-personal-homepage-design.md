# 个人主页设计文档

日期：2026-09-03
状态：已与用户确认

## 目标

一页学术风格个人主页，用于申请/学术用途；GitHub Pages 托管，中英混合内容（以英文为主框架）。技术选型为轻量 Jekyll + YAML 数据文件（方案 A），复用仓库中已有的 Jekyll 依赖。

明确不做：dark mode、博客、访问统计、多页面、成熟学术模板（al-folio 等）。

## 文件结构

```
_config.yml          # 站点名、作者等全局设置
index.html           # 页面主内容：简介、联系方式直接写在此文件
_layouts/home.html   # 页面骨架，用 Liquid 渲染两个数据列表
_data/news.yml            # 新闻条目列表
_data/publications.yml    # 论文条目列表
assets/style.css     # 自写样式（约 150 行）
assets/photo.jpg     # 照片占位，之后由用户替换
```

## 页面布局

整页为一条居中的竖向内容流，各板块同宽对齐（版心约 750px）。页面头部即"介绍块"，其上是页面最顶部，无独立页头行。

```
┌──────────────────────────┐
│ 姓名（介绍块内顶部，居左）    │
│                          │
│ ┌────────────┐ ┌───────┐ │
│ │            │ │ 照片   │ │
│ │  一段话简介  │ ├───────┤ │
│ │            │ │ 联系方式│ │
│ └────────────┘ └───────┘ │
│                          │
│ News                     │
│ ────────────────────────  │
│ Publications             │
│ ────────────────────────  │
└──────────────────────────┘
```

- 介绍块内部为左右两栏：左栏一段话简介；右栏上为照片、下为联系方式（邮箱、Google Scholar/GitHub 等链接）。
- 配色黑白灰，学术页常见朴素排版。
- 窄屏（手机）：右栏折到简介上方堆叠，照片在上（名片式），联系方式随后，再下面是简介。

## 数据维护

- `news.yml`：每条 `{date, text}`，模板按日期倒序渲染。
- `publications.yml`：每条 `{year, authors, title, venue, links}`，`links` 可选（pdf/code）；按年份倒序分组渲染。
- 日常新增内容只改 YAML，不碰 HTML。
- 简介与联系方式改动频率低，直接写在 `index.html`。

## 构建与部署

- 本地预览：`bundle exec jekyll serve`（Ruby/Jekyll 依赖已在 Gemfile/Gemfile.lock 中就绪）。
- 部署：仓库推送到 GitHub，仓库 Settings → Pages 选择 Jekyll 构建，无需 CI。
- 初版使用占位内容（示例姓名、lorem 简介、2-3 条示例 news/publication），构建通过后由用户填入真实内容。

## 测试

静态站点无自动化测试需求；以本地 `jekyll serve` 构建成功、桌面/窄屏两种宽度下布局正确作为验收标准。
